# LectureTranscriptor

Локальное Streamlit-приложение для:
- транскрибации аудио/видео в Markdown;
- быстрого объединения видео и звука через FFmpeg.

## Что умеет сейчас

1. Вкладка `Транскрибация`:
- распознаёт речь из аудио/видео;
- поддерживает режимы: `Транскрибация` и `Перевод на русский`;
- работает с `GPU (CUDA)`, `CPU` или `Авто`;
- показывает прогресс и ETA;
- сохраняет результат в `.md`.

2. Вкладка `Склейка видео + звук`:
- выбирается файл с видео и файл со звуком;
- второй файл может быть и видео: аудиодорожка извлекается автоматически;
- видео сохраняется без перекодирования (`-c:v copy`), исходное разрешение сохраняется;
- аудио кодируется в AAC для совместимости;
- показывает прогресс, приблизительный ETA и live-логи FFmpeg;
- использует те же поля `Папка для результата` и `Имя итогового файла`, что и транскрибация.

## Поддерживаемые форматы

- Для транскрибации: `mp3`, `wav`, `m4a`, `mp4`, `mkv`, `mov`, `webm`, `ogg`.
- Для вкладки склейки:
- Видео: `mp4`, `mkv`, `mov`, `webm`, `avi`, `m4v`.
- Аудио/источник звука: `mp3`, `wav`, `m4a`, `ogg`, `flac`, `aac`, `mp4`, `mkv`, `mov`, `webm`, `avi`, `m4v`.

## Выходные файлы

1. Транскрибация:
- сохраняет в путь из поля `Папка для результата`;
- имя берётся из поля `Имя итогового файла`;
- расширение: `.md`.

2. Склейка:
- сохраняет в путь из поля `Папка для результата`;
- имя берётся из поля `Имя итогового файла`;
- расширение: `.mp4`;
- если файл уже есть, создаётся имя с суффиксом `_2`, `_3` и т.д.

## GPU/CPU в проекте

- Переключатель `Устройство вычислений` влияет на:
- транскрибацию (faster-whisper);
- склейку (параметры запуска FFmpeg: `GPU (CUDA)`, `CPU`, `Авто`).

Примечание: склейка и так очень быстрая за счёт `-c:v copy`, поэтому влияние выбора устройства на неё обычно меньше, чем на транскрибацию.

## Авто-FFmpeg

Приложение само проверяет `ffprobe/ffmpeg`:
- ищет бинарники в локальной папке `_ffmpeg`;
- при необходимости распакует `_ffmpeg.zip`/`ffmpeg.zip`;
- если архивов нет, скачает официальный FFmpeg Essentials.

## Быстрый запуск (Windows)

1. Двойной клик по `Run-App.bat`.
2. Скрипт:
- создаст `env` (если нужно);
- установит зависимости;
- запустит Streamlit на `LectureTranscriptor.py`.

После запуска открой:
- `http://localhost:8501`

## Ручной запуск

```bash
py -3.12 -m venv env
env\Scripts\python -m pip install -U pip wheel
env\Scripts\python -m pip install -r requirements.txt
env\Scripts\python -m streamlit run LectureTranscriptor.py
```

## Зависимости

См. `requirements.txt`:
- `streamlit`
- `faster-whisper`
- `pydub`
- `numpy`

## Структура проекта

```text
LectureTranscriptor/
|- LectureTranscriptor.py

|- requirements.txt
|- out/                # результаты

|- _ct2_cache/
|- _models/
`- .streamlit/
```

## Приватность
