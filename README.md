# ⚡ LectureTranscriptor

> 🎓 Локальное приложение для преобразования **лекций, подкастов, интервью и видео** в структурированные Markdown-конспекты  
> 🎬 + инструмент для быстрой **склейки видео и аудио без перекодирования**

💡 Полностью автономное Streamlit-приложение, работающее локально без облаков и сторонних сервисов.

---

## 🧬 Концепция проекта

**LectureTranscriptor** — это универсальный офлайн-инструмент для работы с медиа:

- 🧠 Распознаёт речь из аудио и видео  
- 🌍 Может переводить речь на русский  
- 📝 Создаёт структурированный конспект с таймкодами  
- 🎬 Позволяет объединять видео и аудио дорожки  
- ⚡ Работает максимально быстро благодаря FFmpeg и faster-whisper  

Проект полностью портативный — все кэши, модели и бинарники могут храниться внутри папки проекта.

---

## 🧠 Основные возможности

### 🧩 Транскрибация

- 🎤 Распознавание речи из аудио и видео  
- 🌍 Режимы:
  - Транскрибация
  - Перевод на русский
- ⏱ Таймкоды `[HH:MM:SS]`
- 📚 Сгруппированные фрагменты речи
- 🧾 Markdown-конспект
- ⚡ GPU (CUDA) / CPU / Авто
- 📊 Прогресс-бар и ETA
- 📁 Сохранение результата в `.md`

---

### 🎬 Склейка видео + звук

- 📼 Выбор файла видео
- 🔊 Выбор отдельного аудиофайла
- 🎥 Второй файл может быть видео — аудио извлекается автоматически
- 🚀 Видео копируется без перекодирования (`-c:v copy`)
- 🔉 Аудио кодируется в AAC для совместимости
- 📐 Исходное разрешение сохраняется
- 📊 Live-логи FFmpeg
- ⏱ Прогресс и ETA
- 💾 Результат — `.mp4`

---

## 🚀 Быстрый запуск (Windows)

### 🔹 Автоматический запуск

1. Дважды кликните `Run-App.bat`
2. Скрипт автоматически:

- создаст виртуальное окружение `env`
- установит зависимости
- подготовит FFmpeg
- запустит приложение

После запуска откройте:

👉 http://localhost:8501

---

## 🛠 Ручной запуск

```bash
py -3.12 -m venv env
env\Scripts\python -m pip install -U pip wheel
env\Scripts\python -m pip install -r requirements.txt
env\Scripts\python -m streamlit run LectureTranscriptor.py
```

---

## ⚡ Автоматическая установка FFmpeg

Приложение проверяет наличие FFmpeg:

1. Ищет бинарники в `_ffmpeg/`
2. Если найден архив `_ffmpeg.zip` или `ffmpeg.zip` — распакует
3. Если нет — скачает официальный FFmpeg Essentials

---

## 🧠 Использование

### Транскрибация

1. Открой вкладку **Транскрибация**
2. Загрузите файл
3. Укажите:
   - папку результата
   - имя файла
   - режим работы
4. Нажмите **Транскрибировать**

Результат — `.md` файл.

---

### Склейка видео и звука

1. Открой вкладку **Склейка видео + звук**
2. Выберите видео
3. Выберите аудио или второй видеофайл
4. Укажите имя и папку
5. Запустите обработку

Результат — `.mp4`

Если файл существует — создаётся имя с суффиксом `_2`, `_3`, и т.д.
